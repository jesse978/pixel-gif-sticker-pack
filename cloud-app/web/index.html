在云端服务的 cloud-app/.env 中配置密钥，然后重启：

OPENAI_API_KEY=你的图像服务密钥
OPENAI_IMAGE_MODEL=gpt-image-1.5

密钥只留在服务端。选择照片不会调用模型，点击生成图集才会发起一次图像编辑请求。费用和素材保留规则以所选服务商为准。当前版本不自动重试付费请求。

没有密钥，也可以导入透明姿势图集，再用原项目合成、预览和导出。导出与示例体验不调用付费模型。

从照片到表情包

  1. 选择素材与表情

    用一张清晰、获准使用的单人照片。也可以导入已生成的透明图集：1 张用 1×1；2 张用 2×1；3–4 张用 2×2；5–8 张用 4×2，空格留透明。

  2. 生成并检查图集

    图像服务根据同一照片生成不同姿势。人工确认人物特征、动作、格子顺序和透明边缘，避免把错误素材带进导出。

  3. 使用原项目导出

    原始 export_pack.py 负责加字、预设动效、透明循环 GIF、技术校验、离线预览页及 ZIP。PNG 是最终 GIF 的首帧。

图像模型可能出现人物细节或姿势变化；相似度需要实际照片验收。此版本使用原项目的轻动效流程，微信等平台的大小与上架要求需另行核对。选择或生成的素材只对本次浏览器会话可见，可随时清除，服务器约 60 分钟后自动删除；外部图像服务的保留规则另计。
